RIKO LIFE Desktop Tools

RIKO LIFE SHOP 内部で使用する Windows デスクトップツール

RIKO LIFE Desktop Tools は、RIKO LIFE SHOP（eBay 輸出販売）が自社の業務のためだけに使用する Windows デスクトップツールです。一般向けに提供・販売しているサービスではありません。利用するのは RIKO LIFE SHOP 自身の Google アカウントだけです。

Google（Gmail API）を使用する機能

Google の Gmail API を使用し、権限（scope）は https://www.googleapis.com/auth/gmail.modify だけを使います。

  • Gmail 通知の読み取り：業務で利用している撮影・発送代行サービス（AUCREVO）から届く通知メール（撮影データ納品・海外発送完了）だけを読み取り、商品写真の差し替え準備や、確定送料の記録に使います。
  • 正常処理済みメールのゴミ箱への移動：ツールで正常に処理し終えた通知メールだけを Gmail のゴミ箱へ移動します（利用者が設定で有効にした場合のみ）。メールの完全削除・送信・作成・ラベル変更・既読化は行いません。

対象のツール

  • 撮影写真差し替えツール
  • 送料確定転記ツール

プライバシーポリシー

Google ユーザーデータの取り扱いについては、プライバシーポリシーをご覧ください。

English summary: RIKO LIFE Desktop Tools are Windows desktop tools used only internally by RIKO LIFE SHOP with its own Google account. They use the Gmail API with the gmail.modify scope only to read business notification emails and to move successfully processed notification emails to Trash. See the Privacy Policy.
